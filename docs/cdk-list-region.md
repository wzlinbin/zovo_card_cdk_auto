# CDK 列表区域

管理员「CDK 列表」在套餐后增加区域列，「本站完整码库」与「卡台状态列表」都显示每张 CDK 创建时的付款地区。

- 明确指定地区：例如 `日本 (JP)`、`智利 (CL)`。
- 创建时使用默认地区：`默认（菲律宾）`。
- 历史本地缓存尚未取得地区：`待同步`；当前页刷新成功后补齐，失败时保留已知地区，不将未知数据当成菲律宾。

列表 API 新增 `payment_country`：字符串是已知创建地区，空字符串表示卡台默认，`null` 表示本地旧缓存尚未同步。字段只用于显示，不改变已发行 CDK 的兑换地区或计费。

发码时保存所选地区；已有的上游列表同步和当前页状态刷新同时保存地区，不增加逐码请求，也不自动扫描整库。旧浏览器回填完整码时未提供地区，不会擦除已有区域。

后端启动时为 SQLite 的 `cardplatform_cdk_codes` 增加可空 `payment_country` 列，旧行保留为 NULL。更新本功能需要同时更新后端与前端；不需要重新生成或兑换卡密。
